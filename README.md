Me especializo en ciberseguridad, análisis de vulnerabilidades y el desarrollo de sistemas robustos. Me destaco por mi capacidad para analizar infraestructuras, identificar debilidades y pensar "fuera de la caja" para encontrar vías de explotación y solución. Mis áreas de mayor fortaleza incluyen:

- **Resolución de CTFs (Capture The Flag)**: Documento mis metodologías ("writeups") paso a paso para retos de seguridad en categorías como Hacking Web, Criptografía, Esteganografía, Ingeniería Inversa (Reversing) y Explotación de Binarios (Pwn).
- **Hacking Ético y Pentesting**: Evaluación de aplicaciones web e infraestructuras con el objetivo de asegurar sistemas críticos.
- **Algoritmia y Estructuras de Datos**: Resolución lógica de retos de código y optimización de algoritmos.
- **Desarrollo**: Construcción de plataformas, automatizaciones y scripts ofensivos/defensivos.

## 💻 Sobre este Repositorio

Este repositorio contiene el código fuente de mi sitio web personal. Ha sido diseñado desde cero buscando no solo cumplir su función como blog, sino también demostrar un alto estándar de diseño, fluidez y experiencia de usuario (UX).

### Tecnologías Clave:
- **Motor principal**: Construido sobre **[Astro](https://astro.build/)** para generar un sitio estático increíblemente rápido con un rendimiento 100/100 en Lighthouse.
- **Estilización**: **Tailwind CSS**, implementando un diseño profesional con soporte nativo para **Modo Oscuro**, componentes *Glassmorphism* limpios y diseños responsivos mediante *Flexbox/Grid*.
- **Bloques de Código**: Motor de sintaxis de alto nivel (`astro-expressive-code`) con temas de terminal modernos (`tokyo-night`) ideales para leer comandos bash, scripts de python y análisis de exploits.
- **Gestión de Contenidos**: Colecciones de contenido tipadas en MDX y Markdown, organizando eficientemente mis artículos regulares, tutoriales de código y writeups exhaustivos de CTFs.
